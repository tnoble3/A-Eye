# UI Direction

The popup UI is moving toward a grounded visual style rather than a generic
developer tool look.

## Current Direction

- Soft sand-and-sage palette for a calm but analytical feel
- Rounded cards and layered surfaces to separate score output from signal detail
- Clear hierarchy with a dominant confidence number and smaller diagnostic cards

## Reasoning

The extension should feel lightweight and readable because users will interact
with it in short bursts while browsing. The current color and layout choices
support quick scanning without making the detector feel overly alarmist.
